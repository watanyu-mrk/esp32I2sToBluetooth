    ลำโพง Bluetooth

      กำลังค้นหาอุปกรณ์…

      บอร์ดนี้

      ใช้ตอบเมื่ออุปกรณ์ปลายทางขอรหัส เช่น เครื่องเล่นในรถที่ต้องใส่ 0000 — เว้นว่าง = ใช้ค่าเริ่มต้นของไลบรารี (1234)

      ปิดไว้สำหรับเครื่องเล่น/ลำโพงรุ่นเก่าที่ขอรหัส PIN แบบเดิม

      เสียง

      ตั้งทุกครั้งที่ลำโพงเริ่มเล่น — ลำโพงมักกลับไปดังสุดเองเมื่อปิด/เปิดเครื่อง ค่านี้จึงถูกส่งไปให้ลำโพงใหม่ทุกครั้งที่เริ่มสตรีม (127 = ดังสุด, 0 = เงียบ)

      บัฟเฟอร์ที่ใหญ่ขึ้นทนช่วงที่ Wi-Fi สะดุดได้นานขึ้น แต่เสียงจะช้าลง

      44100 Hz · PCM16 stereo

      SBC encoder ของ Bluedroid รับ PCM 44100 Hz คงที่ สตรีมที่มาในอัตราอื่นจะถูกแปลงให้อัตโนมัติ

      หลังบันทึก บอร์ดจะรีสตาร์ท 1 รอบ แล้วกลับไปเชื่อมต่อ Wi-Fi/ลำโพงด้วยค่าใหม่

      หน้าตั้งค่านี้เข้าถึงได้จาก IP ของบอร์ดในวง Wi-Fi เดียวกัน หรือ AP ESP32-Radio-Setup (รหัส esp32radio) ที่ http://192.168.4.1/
